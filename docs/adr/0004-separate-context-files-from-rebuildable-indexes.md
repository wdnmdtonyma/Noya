# Keep authoritative context in files with rebuildable indexes

Noya keeps authoritative context in schema-validated structured files, groups world content into subtrees that can be split across files using stable node references, and derives local indexes for IDs, titles, summaries, types, ancestry, and file locations. The Context Agent interprets user intent and uses deterministic local tools to search summaries and detailed content, read individual nodes, or batch-read selected nodes and subtrees; reading a file internally does not require returning the entire file to the model. Indexes are refreshed from saved content and can be rebuilt, while automatic size-based splitting, a separate natural-language retrieval service, mandatory vector search, and a specific index backend are outside the MVP commitment; efficiency must be evaluated on real retrieval and chapter-preparation tasks rather than assumed from file layout alone.
