# Noya · 理想方案 · 用户故事与动线

> 2026-07-22 定稿口径：本方案不做发布（只到成稿＋导出）、不做巡航（永远一章一拍）、不做分叉时间线（单线）。

## 一、这个人是谁

一个想靠网文赚点钱的人。有故事欲，但卡在几个地方：码字慢（一天两千字，可商业连载要日更六千）；写着写着跑偏，第三十章还没进主线；不知道市场现在要什么；一个人写没人接话，写到二十万字弃坑。

他不是专业作家，也不想变成专业作家。他要的是——**我做决定，别人干活**。

本方案只服务他一个人，没有协作、没有分享。

---

## 二、四个故事

### 故事一 · 第一夜：从"想写个修仙的"到三章正文

晚上十点，他脑子里只有"想写个修仙的"，别的没了。

打开 Noya，屏幕几乎全黑，中间一行字问他想写点什么，底下一个框。他打了一句："修仙，社畜穿越，靠签到变强。"

三颗书种摆出来，每颗一句话设定加主角加金手指加开局怎么起，还各带一句为什么是它（这一路现在还在烧、这一路人多但盘子大）。他挑了第二颗，觉得主角名字土，说"主角改叫林凡"。

世界从雾里长出来：外门弟子院亮了一块，一个小人站在里面，顶上时间线只有"开篇前夜"四个字。

Agent 问他第一章想让什么发生。他说"让他一上来就被人当众羞辱"。

一章两千六百字写出来。地图上多了个反派，时间线长一格，左上角从"尚未落笔"变成"2,600 字 · 1 章"。

他接着说了两次。四十分钟后，他有了三章、一个五个人的世界、一条 0.7% 的死线。Agent 问："这个开局你要不要？"他说要。

**这一晚他做的所有事，是打了五句话。**

### 故事二 · 第二十天：日常的一小时

下班回来打开，Agent 一句话把他接上："上次停在第 12 章，林凡刚进坊市，你说要让他碰见沈青霜。"

他说"碰见，但别认出来"。

Agent 提议这一章怎么演，四件事一起给：大概剧情；看点怎么演到位（她认出他腰上那块玉，但不说破）；这章谁登场（沈青霜长期，卖玉老板一次性）；谁知道什么（她知道玉的来历，他不知道她知道）；章末钩（她转身前留下一句话）。

他觉得卖玉老板多余，说"换成上次那个王二狗"。Agent 改了，他点头，一章写出来。

一小时三章。坊市从雾里出来了，沈青霜那条线亮了。

睡前他点开册子看了眼欠账：韩拾遗的身份欠了三十章没还。他说"下一章让老头开口"。Agent 说好。

### 故事三 · 第四十天：出事的三种样子

**他自己写了一段。** 手痒，写得挺爽，贴进去。Agent 先反问一句"这是第 33 章的正文，还是给我参考的资料"，他说正文。Agent 读完说：你这段里他已经筑基了，但世界里他是炼气一层，还欠着大比那条死线，以哪个为准？他一拍脑袋，说"改我写的这段"。

**他发现写歪了。** 第三十二章不对味，他说"打回重写"。Agent 先摆代价：这一章带来的那个新角色会退场；坊市不受影响（早就有了）；你自己写的那段不在这一章里，不动。他说撤。世界退回去，雾重新合上一块。

**他想换设定。** "签到系统太老套了，改成吞噬。"Agent 给影响范围：四十七章、三个人的动机、两处地方的意义。两条路：从这章起改（前面不动）或者全书回改。他选前者。Agent 把矛盾的章列了个单子，他一条条回："这条接受、这条重写、这条不管。"

### 故事四 · 第八十天：收尾

三十万字。他说"这本我想收了"。

Agent 盘账：五笔没还，其中三笔必须还（韩拾遗的身份、赵天雄的禁药、沈青霜的旧情），两笔可以弃。给了一个十二章的收尾方案。

他改了一句"沈青霜那条别圆得太满，留点余味"。写完，他说"导出"，拿到一个 txt。

**之后他自己拿去番茄发——产品不管这一步。** 哪天想加个番外，或者想接着写第二卷，说一句就能回来。

## 三、动线

### 入口（三种状态）

- **没有书**：Agent 开口问"想写点什么"
- **有一本书**：直接落回那本，Agent 一句话接上上次停在哪
- **有多本书**：落回上次那本，顺带一句"另外两本：怪谈停在第 5 章，都市还没开头"；随时说"我有哪些书"能唤出书架

### 主干（唯一的循环，一章一拍）

```
Agent 提议这一章（剧情 / 看点怎么演 / 谁登场·长期还是一次性 / 谁知道什么 / 章末钩）
      ↓
你点头，或改一句，或说个别的方向
      ↓
写一章
      ↓
世界长：地图（雾退开 / 新地点 / 新人物 / 标记变）· 时间线 +1 · 册子更新 · 字数涨
      ↓
Agent 留一个问题
      ↓
回到开头
```

节奏只有这一种。**没有后台任务，没有"它背着我写了一堆"这种状态。** 你不在，世界不动。

### 九条岔路（每条都规定了怎么回主干）

1. **我自己写这一章** → 贴文 → Agent 反问"正文还是参考资料" → 吸收，并列出它读到的人/地/事/账 → 你可以逐条改判（"孙彪不是一次性，后面还有戏"）→ 回主干
2. **我要改** → 四档：调文风（往后所有章的写法，事实不动）／润色单句（触到已定事实时提示转打回）／打回重写（讲代价 → 确认 → 回滚）／动设定的根（给影响范围 → 选从这章起改还是全书回改 → 矛盾章逐条处理）→ 回主干
3. **我要问一句** → 疑问句只答不写，答完明说"这个我只是查了，世界没动" → 回主干
4. **我要看** → 册子（人物·大事记·两本账）／正文／主角面板（属性·背包·系统任务）→ 关掉 → 回主干
5. **我后悔了** → 说"刚才那步不算" → 退回上一步（有效到下次改动世界为止）→ 回主干
6. **一卷收了** → Agent 盘未还的账 → 你定卷二还哪几笔 → 镜头拉远、地图长出下一层 → 回主干
7. **开局关口**（只在第三章后出现一次）→ 要 / 不要（回炉大纲 或 换一颗书种重来）→ 回主干
8. **换本书 / 开新书** → 书架 → 进另一本的主干；也可以说"这本不要了"（先算代价再确认）
9. **收了这本** → 盘账 → 收尾方案（可改）→ 写完 → 导出；之后可写番外（写完回主线，并问番外的事实要不要入世界），也可说"我还想接着写"把书退回连载态

### 出口

导出成稿（txt / word）。关掉窗口——世界停在那一刻，下次打开 Agent 接上。

## 四、三条保证：为什么不会不知道下一步

1. Agent 每次收尾都留一个问题，不是等你想
2. 框下永远有两三个快捷说法，点了等于替你打字，也可以完全不理
3. 地图上永远有一个呼吸的光点，标着下一段会发生在哪儿

**功能发现不靠菜单，靠 Agent 在合适的时候开口。** 这是模型最大的假设，也是最大的风险。

## 五、高代价动作的三步

凡是会破坏世界的动作（打回重写、动设定的根、丢掉一本书），一律：

1. **先讲代价**：谁会退场、哪块地会盖回雾里、哪笔账退回欠着、你自己写的内容动不动
2. **等你确认**：复述一遍再动手（自然语言的误解率比按按钮高）
3. **留一步反悔**：做完还能说"刚才那步不算"

已发布过的章是硬底——但本方案不做发布，所以这条只在你自己标记过"这些我发出去了"时生效。

## 六、本方案明确不做

- **发布**：不代发、不读平台数据、不做运营建议。写完导出，你自己去发。
- **巡航**：不连写多章。砍掉它顺带砍掉了三件事——冲突分级（小冲突记账续跑）不需要了，因为每章都在你眼前写、有冲突当场问；跨书不打断不需要了；"完成通知"也不需要了。
- **分叉时间线**：单线。重生流的前世线用回忆承担，不做双线并行。
- 多人协作、分享、评论；本产品自己的埋点；放置玩法（你不在时世界不会自己动）。
