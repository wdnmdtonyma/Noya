# Noya · 小说世界模型 v4 (2026-07-14)

> **产品脊椎。** 所有台面(用户看的)、Agent 写作、一致性守护、章节回写,都读写这份世界状态。
> **定位**:人当导演/落子、Agent 当写手码字;自用;本方案到成稿;游戏式。**魂**:造一局你自己的世界,玩着玩着书就写成了。
> **两个面**:**台面**(用户摸的卡/图/板,只碰这个) / **底层管线**(给 Agent 和一致性守护,用户永不见)。
> **题材化**:种类固定,成员/脸随题材伸缩。
> **本方案一次性啃下**系统流+穿越的硬骨头——但**啃下 ≠ 摊给用户**:复杂度全压在管线+Agent,台面不露。

## A. 底层管线

**四种存储 kind**
1. **实体**——设定 / 角色 / 时间线 / 数值账本(题材)
   - 设定:规则/禁忌/金手指;空间(地图)是它的一张题材脸;**空间/场景带感官锚点**(光线/气味/声响/材质),够写手起画面、够守护认场景一致
   - 角色:档案 + **形象**(外貌/衣着/体格/气场——女主、反派、常驻角色尤其必填,防"每卷长得不一样") + 技能道具 + 声口 + 目的 + **秘密·底牌**
   - 时间线:进程;能装分叉/反事实;**事件只存一次**
   - 数值账本(题材触发):积分/货币/库存,带守恒;**由"系统/金手指"持有(见下)**
2. **边**——关系网(角色间的边,权重/演化)
3. **派生视图**——未结之事索引(伏笔/目标/冲突/爽点债 + 状态);只读不双写
4. **透镜**——把世界状态渲染给某个消费者,**不新增世界事实**
   - **风格透镜**:世界 → 读者(叙述声/节奏/视角/人称);角色台词声口不在这
   - **系统 HUD 透镜(题材触发)**:世界事实 → 主角(游戏化面板);见下"系统/金手指"

**系统 / 金手指(题材触发的特殊件——一次补上"系统声口无家"+"字母穿帮")**
系统流的"系统"既不是普通角色、也不只是账本,是三合一特殊件:
- **持有数值账本**(道源/积分/库存 的真源)
- **有自己的声口**(机械腔「叮——」,可带 deadpan/傲娇人格)——**声口挂在这**,补上"声口只能挂角色、但系统不是角色"的洞
- **是一层 HUD 透镜**:把世界事实**渲染**成游戏化词汇给主角看——**字母/评分/百分比是这层"渲染",不是世界事实本身**
  - 世界事实"五行杂·废灵根" → 系统渲染"资质 F";世界事实"修为浅" → 系统渲染"12% / 战力 108"
  - **作用域 = 只有主角+读者看得见**(NPC 永远看不到面板,只看见"一个废柴");靠认知/作用域圈死,呼应主角"有系统=无人知"的底牌

**两根坐标轴**(给每条事实打坐标,本身不存东西)
- **分支**:时间线的分叉/反事实(前世线/今世线/分歧点)——重生
- **作用域**:世界实例(主世界/位面/副本)——位面穿越/无限流
- **实体定位 = (分支, 作用域) 联合坐标**
- **穿越范式(理清 v3 的骑墙)**:一次"穿越/魂穿"可能同时动两个坐标——纯位面穿越=只换**作用域**;重生=只换**分支**;魂穿+带前世记忆/系统=**两者都换**,记成**两次显式移动/转账**(记忆一次跨作用域携带,数值一次跨分支转账),不当一次移动。换世界实例=作用域,回到过去/反事实=分支,可叠加

**认知(小机制,不是一等 kind)**
- **角色秘密·底牌**:每人几条关键秘密(手写,十几条量级封顶),按 (分支,作用域) 打标
- **守护一条防穿帮查表**:"角色 A 这会儿知道 X 吗?草稿用了 → 报警"
- **读者侧**:不做仪表;Agent 觉得"读者怕是猜到/等腻了"时递一句提示;"读者在等啥"复用未结之事,不另存

**跨轴规则 + 账本↔角色 流转通道**
- 账本**每账户声明绑定**(全局/系统绑/作用域本地);守恒**按账户各算**;跨界记**显式转账分录**;离开作用域,本地账户冻结归档
- 派生视图/关系/未收线**只投影"活分支 + 当前作用域"**;本地线离场自动归档;唯有主角"跨界携带"的线显式穿墙;NPC 默认被墙在本分支本作用域
- **物品唯一真源 = 库存**:"装备/学会"是角色上的一个**状态位 + 对库存条目的引用**,不复制第二份(秘籍买入进库存 → 修炼后角色技能位标"已掌握·引用#该秘籍",库存条目转"已内化",全程一份真源,不双写)
- **账本消费改写角色属性 = 一个显式"系统写入事件"记在时间线**:洗髓丹改灵根、直充改修为,都是"系统→角色属性"的写入事件,角色属性是被写入方,账本只扣道源
- **修为/境界真源 = 角色状态 + 时间线事件**;账本"直充修为"只是给这个真源灌值的通道,不另存一份;账本只存自己的量(道源/签到天数/战力评定)。**"等级"分两种:境界等级(设定阶梯+角色状态)≠ 系统账本等级(签到天数/战力评定),别混**

**建模纪律**
- 事件只在时间线存一次;故事线/伏笔/未结之事/冲突都是其上的派生视图,不双写
- 因/果 = 同一份世界状态的"生产者/消费者方向",不是两份存储

## B. 台面:用户实际摸到的东西

结构是 **1 个工作台 + 一排按需参考卡**,不是平铺清单。

- **工作台 · 落子简报(90% 时间活在这)**:Agent 每次先落好一个完整的子(章纲/结局/危险度/量级排好),简报把它 + 用到的料铺给你。你默认**过目 / 否 / 微调**。
- **按需参考卡(要用才翻)**:角色卡(+形象+底牌)、剧情线、关系网、世界设定、地图、文风。
- **题材触发的台面(点亮才有)**:资源账本面板(系统流/经营流)、副本/位面切换(穿越/无限流)。
- **不上台面(留在管线给 Agent)**:未结之事、读者认知——折成简报里的一行提示。

## C. 交互原则
1. **Agent 先落子,你过目/否/微调**——你是导演不是分析师;简报是"Agent 用到的料",不是你的阅读作业。
2. **一个工作台 + 按需参考卡**——只活在落子简报,其余要用才翻。
3. **结构直接点、味道走对话**——数值/标签/章纲每拍/装备/阵营 一律 inline 点;对话只留给"点不出来的感觉"。
4. **上帝操作按需现身**——分叉/作用域切换只在穿越·开新副本那一拍出现;平时隐式锁死当前线+scope。

## D. 叙事纪律(执行侧——模型给真源,Agent 保证不串味)
承接"系统 HUD 透镜":模型把"世界事实"和"系统渲染"分了家,**Agent 落笔必须守住这条线**——
- **叙事层(旁白 + NPC 台词 + 世间描写)只用世界内词汇**:"废物、五行杂灵根、下等资质、蝼蚁般的修为";**绝不出现 A/B/C/F 级、108、12% 这类系统词汇**。
- **系统词汇只活在系统面板 + 主角对自己面板的内部引用里**。
- **一致性守护加一条检查**(和防穿帮同类):系统专有词(字母级/数值评分/百分比/"面板")出现在叙事层 → 报警。
- **软默认(题材味)**:连系统面板里,评级也优先用修仙本土词(天地玄黄品 / 上中下 / 九品)而非 A-F 字母;数值/百分比这类"系统就是要量化"的保留(系统流本色)。字母级最出戏,非有意为之(比如系统本就是被移植的游戏 UI、且是剧情梗)不用。

## E. 本方案范围
- 一次性啃下:数值账本 + 分叉时间线 + 作用域 + 系统/金手指件;本方案同时能写系统流和穿越,不锁题材。
- 四种 kind + 两坐标轴 + 系统件 + 认知小机制 全实装;台面按"工作台 + 参考卡"摆;题材台面按题材点亮。
- 啃下的复杂度全在管线+Agent,台面只多"账本面板 / 位面切换"两块按需出现的东西。
