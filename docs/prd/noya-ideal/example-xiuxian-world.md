# 世界模型实例 · 系统流修仙 ·《我在青云宗打卡修仙》

> **用途**:对 Noya 世界模型 v3(见 `world-model.md`)的一次真实实例化验证。严格按 v3 的四 kind + 两坐标轴 + 认知小机制 + 跨轴规则填满,供另一个 agent 直接开写前三章。
> **题材**:系统流(签到/打卡)修仙 + 魂穿。番茄/七猫免费向。
> **一句话**:地球扑街打工人魂穿青云宗最废外门弟子,绑定「长生签到系统」——签到得道源、商店换资源,从 F 级废灵根一路苟成大佬。
> **书名对照**:与既有怪谈例《我在规则怪谈里开民宿》同构(我在___里___),这里是同一套模型换题材脸。

## 0. 坐标轴先行(一切事实都挂在这上面)

模型说"实体定位 =(分支, 作用域)联合坐标",所以先把两根轴的取值定死,后面每条料都带坐标标。

### 作用域(世界实例)
| 作用域 | 状态 | 说明 |
|---|---|---|
| `地球·现代` | **归档** | 主角前世所在实例。魂穿后离场,整份归档;NPC(主角前世亲友)被墙在此,不投影。 |
| `玄苍界·主世界` | **活** | 故事主战场。青云宗、外门、藏经阁、后山都在这。 |
| `青冥秘境`(潜伏) | 未开 | 卷一后段开的副本 scope。灵石在此冻结,用本地「秘境贡献点」。前三章只作伏笔,不实例化。 |

### 分支(时间线分叉/反事实)
| 分支 | 状态 | 说明 |
|---|---|---|
| `今世线` | **活** | 林凡(主角)接手身体后的主线。 |
| `前宿主线·陆沉` | **归档(反事实)** | 分歧点 =「系统重置·陆沉之死」。系统上一任宿主陆沉百年前在玄苍界失败身死,系统软重置、回溯换绑,岔出今世线。此线整体归档,**唯有系统把一部分数据跨分歧点携带过来**(见账本分录 0)。前三章主角对此一无所知(深埋伏笔)。 |

### 主角的两条"跨界携带"通道(唯一被允许穿墙的例外)
1. **跨作用域携带**:主角带着 `地球·现代` 的记忆/见闻/网文常识过来 → 标 `携带:作用域 地球→玄苍界`。
2. **跨分支携带**:系统带着 `前宿主线·陆沉` 的残留(道源余额、部分商店解锁)过来 → 标 `携带:分支 陆沉线→今世线`。

> 这两条是**两次独立的跨界**,被"魂穿"这一件事捆在一起——见文末摩擦 #4。

**默认锁**:除上面两条显式穿墙线,派生视图 / 关系网 / 未结之事一律**只投影 `今世线 + 玄苍界·主世界`**。所有 NPC(沈青霜、赵天雄、王二狗、韩拾遗)默认被墙在 `今世线·玄苍界`。

## 1. 实体 · 设定(规则/禁忌/金手指 + 修仙体系 + 地图脸)

> 修仙的"体系类"设定都放这:境界阶梯、功法/法宝/丹药的品阶规则、灵根规则、金手指规则。**注意区分**:体系的*定义*是设定;某个角色*当前站在哪一级*是角色状态;某次*突破*是时间线事件。

### 1.1 世界规则(金手指规则)
- 修仙世界灵气为本,凡人吸灵气入体炼化→修为。灵根决定吸收效率与上限。
- **金手指 =「长生签到系统」**:只绑定主角一人。核心闭环 = **签到攒道源 → 系统商店换一切(功法/丹药/法宝/灵根改造/直充修为)**。系统即本书数值账本的"题材脸"(账本细节见 §5)。
- **金手指代价/软约束**(给爽感上锁,防无脑):
  - 道源只能靠签到与系统任务获得,**不能靠杀人抢劫直接变现**(逼主角"苟"、日拱一卒)。
  - 商店按签到天数分层解锁,越级资源买不到(见 §5 商店 tier)。
  - 越境界服丹/硬突破有**心魔/业力**风险,只能用**功德**抵消(见账本第二账户)——这是把"系统流无脑变强"扣回修仙逻辑的闸。

### 1.2 境界体系(逐级 · 这是"等级"阶梯,属于设定)
炼气 → 筑基 → 金丹 → 元婴 → 化神 → 炼虚 → 合体 → 大乘 → 渡劫飞升。

| # | 境界 | 细分 | 备注 |
|---|---|---|---|
| 1 | **炼气** | 一~九层 | 凡人起步,林凡在此(一层)。 |
| 2 | **筑基** | 前/中/后/大圆满 | 外门弟子天花板;卷一目标线。 |
| 3 | **金丹** | 结丹后分品(一~九品金丹) | 内门/长老级。 |
| 4 | **元婴** | 前/中/后期 | 太上长老级。 |
| 5 | **化神** | — | 一宗之祖。 |
| 6 | 炼虚 | — | 传说。 |
| 7 | 合体 | — | 传说。 |
| 8 | 大乘 | — | 传说。 |
| 9 | 渡劫飞升 | — | 飞升上界(全书天花板/远景)。 |

> **谁拥有"等级"这个概念**:阶梯定义在此(设定);林凡"炼气一层"是角色状态;系统还额外维护一个**签到天数/宿主等级**(账本里,gate 商店)。同一个"等级"直觉被摊在设定+角色+账本三处——见文末摩擦 #5。

### 1.3 功法 / 法宝 / 丹药的品阶规则(设定)
- **品阶**:黄 < 玄 < 地 < 天 <（仙),每品分上/中/下。
- **功法**:决定修炼速度、法术、战力上限。规则在此;**某个具体功法**是"角色技能位"(已学)或"账本库存"(未学的秘籍)——见摩擦 #1。
- **法宝**:法器(炼气用)< 灵器(筑基)< 宝器(金丹)< …。具体法宝挂角色道具格 / 账本库存。
- **丹药**:聚气丹/筑基丹/洗髓丹…,消耗型,挂账本库存。
- **灵根/资质**:天灵根(单系,S) > 变异灵根 > 双灵根 > 三/四/五行杂灵根(伪,F)。**灵根是角色档案字段**,但**系统商店的洗髓丹能改写它**——跨 kind 写,见摩擦 #3。

### 1.4 空间(设定的一张题材脸 · 地图)
起点自内向外:**外门弟子院(起点/主签到点)** → 藏经阁(隐藏签到福地,道源 ×5) → 演武场(外门大比场地) → 内门(沈青霜所在) → 后山灵田/禁地 → `青冥秘境`(卷一后段开的副本 scope)。
- 坐标:全部 `(今世线, 玄苍界·主世界)`。
- 灵气系数(喂给签到公式):外门院 ×2、藏经阁 ×5、洞天福地 ×10、秘境 ×20。

## 2. 实体 · 角色(档案 + 技能道具 + 声口 + 目的 + 秘密·底牌)

> 仙侠角色卡字段(prd.yaml 口径):境界 / 法宝 / 功法 / 等级 / 正反派 + 当前状态。每张卡带坐标标。

### 2.1 林凡 · 主角(穿越者)· `(今世线, 玄苍界·主世界)`
- **档案**:17 岁,青云宗外门弟子。**灵根**:五行杂·伪灵根(资质 F)。**境界**:炼气一层(修为 12%)。**正反派**:主角。
- **原主设定**:原身"林凡"是外门垫底废柴,因灵根废常年被欺;魂穿发生在被赵天雄堵着羞辱、几近绝境的那一刻,系统随之觉醒。
- **金手指/技能位(功法)**:《引气诀》(黄阶下品,原主自带,龟速)。绑定「长生签到系统」。
- **道具格**:生锈铁剑 ×1、下品灵石 ×3、半块干粮。
- **声口**(台词语域/口头禅,**存在角色实体上,不进风格透镜**):现代打工人嘴替 + 老网文读者吐槽体;心理 OS 密集(番茄爱看)。口头禅:"这不比上班强?""签到,启动!""稳住,别浪——先苟。"表面对外**装怂**(扮猪吃老虎),内心毒舌。
- **目的**:短期——三月后外门大比别垫底、别被逐出宗门;长期——回不去地球,那就修仙长生、苟成大佬。
- **秘密·底牌**:
  1. **穿越者身份** — `携带:作用域 地球→玄苍界`。除他自己无人知。
  2. **有系统** — 无人知(卷一唯一例外:韩拾遗隐约察觉,见 2.4)。
  3. **系统来历/前宿主陆沉** — `携带:分支 陆沉线→今世线`;**连主角自己都不知道**(100 道源哪来的、系统为何选他,深埋)。
  4. **装怂是装的**。

### 2.2 沈青霜 · 女主/悬 · `(今世线, 玄苍界·主世界)`
- **档案**:内门第一天才女修,**灵根**:太冰灵根(变异,S-);**境界**:筑基前期;**正反派**:友方(暂高冷/中立)。用剑。
- **法宝**:寒潭剑(灵器下品)。**功法**:《太阴凝霜诀》(地阶)。
- **声口**:话少、句短、冷;偶尔一句噎死人。无口头禅,靠"沉默 + 精准一击"。
- **目的**:借外门大比暗中物色一个"看不透的人"(她隐隐锁定灵气异动的林凡)。
- **秘密·底牌**:①身负「北冥剑冢」隐世传人身份(未挖);②她已**察觉林凡签到时的一缕反常灵气**,正暗中观察——但**不知道那是穿越/系统**(防穿帮关键,见 §9)。
- **与主角**:原主曾在她受困时替她挡过一剑(旧事),她记这份情——关系起点。

### 2.3 赵天雄 · 反派(第一个打脸靶)· `(今世线, 玄苍界·主世界)`
- **档案**:外门第一人,长老赵铁山之侄;**灵根**:火单灵根(A);**境界**:炼气七层;**正反派**:反派(外门恶霸)。
- **法宝**:烈阳环(法器上品)。**功法**:《焚天诀》。
- **声口**:居高临下、爱立威、口头禅"废物也配……";急了破音。
- **目的**:大比夺魁进内门 + 追沈青霜(单方面觊觎);顺手拿林凡当垫脚立威。
- **秘密·底牌**:偷服**禁药「嗜血丹」**速成(魔功副作用),这是把柄+定时炸弹(伏笔)。
- **与主角**:开局即欺压,直接矛盾,权重强负。

### 2.4 韩拾遗 · 引路人/谜(扫地深藏)· `(今世线, 玄苍界·主世界)`
- **档案**:藏经阁掌书老杂役,表面炼气残废、扫地打杂;实则**元婴期落魄太上长老**(隐藏,慎用)。

- **与主角**:表面上下级,暗线↑(他单向知情)。

### 2.5 王二狗 · 损友/信息源 · `(今世线, 玄苍界·主世界)`
- **档案**:外门底层杂役弟子,炼气二层,五短身材;**正反派**:友方(搞笑+信息)。
- **声口**:市井、话痨、消息灵通,口头禅"哥,我跟你讲——";怂但仗义。
- **目的**:混口饭吃、抱林凡大腿(直觉这兄弟要起飞)。
- **秘密**:无关键底牌(平民视角,负责把宗门八卦/大比规则自然说给读者听)。

## 4. 实体 · 数值账本(系统 · 本书核心 · 硬核)

> 题材触发的一等实体。系统 =「长生签到系统」,即账本的题材脸。下面把"给什么/怎么算/卖什么/属性面板/等级/获得消耗/守恒/账户绑定/初始值"全部钉死。

### 4.1 三个账户 + 绑定(刻意覆盖三种绑定各一)
| 账户 | 绑定类型 | 怎么获得 | 怎么消耗 | 守恒范围 | 初始值 |
|---|---|---|---|---|---|
| **道源点(道源)** | **系统绑** | 签到、系统任务、首次突破奖励 | 系统商店(功法/丹药/法宝/灵根改造/直充修为) | 单一系统池,每笔带分录,期初+Σ收入−Σ支出=期末 | **100**(来自分录 0) |
| **功德** | **全局绑** | 救人、斩妖除魔、行善(世界行为,**非系统任务**,天道自动记功) | 抵消心魔/业力、功德专属商店(保命符/洗杀孽) | 全局唯一池(灵魂属性),跨一切 scope+branch | **0**(原主怂废,没积过) |
| **灵石(下品)** | **作用域本地(玄苍界)** | 卖东西、宗门月俸、任务赏 | 买凡俗物资、宗门交易 | 仅本作用域内守恒 | **3** |

**跨轴行为**(直接兑现 world-model 的跨轴规则):
- 道源 = 系统绑 → 主角入 `青冥秘境`(新 scope),**整账随宿主穿墙,继续可用**(系统流不断电)。
- 灵石 = 作用域本地 → 入秘境**冻结归档**,秘境内改用本地「秘境贡献点」;出秘境解冻。
- 功德 = 全局绑 → 处处通用,秘境/位面都认。
- 三账户守恒**各算各的**,互不混池;跨界流动必须走**显式转账分录**(见分录 0)。

### 4.2 签到规则(道源怎么算)
- **每日限一次**,在当前所在地点签到。
- `道源 = 基础10 × 地点灵气系数`。外门院 ×2=**20**;藏经阁 ×5=**50**;洞天福地 ×10;秘境 ×20。
- **连续签到 → 签到天数**(streak):满 7/30/100 天解锁更高商店 tier + 额外礼包。
- **首访新地点**:一次性探索 bonus(藏经阁首访 +100)。
- **首次突破新境界**:大额 bonus(炼气→筑基 +500)。

## 10. 实例化时的模型摩擦(验证关键 · 老实记)

按这个模型往里填,以下 4 处让我觉得**缺家 / 得塞两处 / 规则没讲清**,具体到位:

### 摩擦 #1 —— 功法/法宝是"角色技能位"还是"账本库存"?同一个东西双栖无家,还有双写风险。
我想放《寒霜真解》这本功法。**未学时**它是系统商店里的一件商品、买下后进背包 → 该在**账本·库存**;**学会后**它是林凡的一个战斗技能 → 该在**角色·技能位**。模型把"技能位"(角色)和"库存"(账本)列成两个不同的家,却**没给同一对象在两处之间迁移的规则**:买入(库存 +1)→ 修炼 → 变成技能(技能位 +1,库存 −1)这条链,是一次转账?还是先删后建?建模纪律说"不双写",但一本秘籍在"拥有"和"会用"两个语义下天然要同时被库存和技能位关心——**到底谁是唯一真源,模型没定**。法宝(青锋剑:既是库存道具又是出战装备)同理。

### 摩擦 #2 —— 系统的"声口/人格"无处安放。
系统流的读感有一大半靠**系统那把机械腔**(「叮——宿主…」,偶尔还有点小傲娇/毒舌人格)。模型明说"角色台词声口在角色实体上、不在风格透镜",可**系统不是角色 kind,是数值账本 kind**。于是系统的台词语域**没有家**:塞进风格透镜(违反"声口不在透镜")?还是被迫给系统建一个"角色"分身(那它的账本又该谁持有,自我指涉很怪)?系统到底算不算一个会说话的"角色",模型没表态——但这是系统流最出彩的表达位。

### 摩擦 #3 —— "花道源改灵根/直充修为"是账本跨 kind 写角色档案,且"修为进度"到底归哪个 kind 说不清。
洗髓丹(账本商品)一吃,**改写的是角色档案里的"灵根"字段**;直充修为(账本)改写的是"修为进度"。模型把"积分/货币/等级/库存"(账本)和"角色档案"分成两个 kind,却**没有声明一条"账本消费 → 改写角色属性"的合法通道**,现在只能靠隐式约定。更别扭的是**"修为进度"本身归属暧昧**:直充 +1% 把它当**账本余额**(要守恒、可购买);而"突破炼气二层"又把它当**角色里程碑 / 时间线事件**。同一个"修为"被账本和角色/时间线三方争夺,守恒该不该管它、它算不算一笔"库存"——模型没划线。

### 摩擦 #4 —— "穿越"一件事同时动了两根轴,模型没说这是一次移动还是两次;且模型自己对"穿越挂哪根轴"就骑墙。
我这个主角的"魂穿"实际是**两次独立跨界捆在一起**:(a)跨**作用域** `地球→玄苍界`(携带记忆),(b)跨**分支** `陆沉线→今世线`(系统携带道源余额)。模型说"实体定位=(分支,作用域)联合坐标",但**没讲一个同时改变两个坐标分量的跨界事件怎么记**——是一条移动、还是拆成两条转账/两次穿墙?我这里被迫拆成两条(记忆携带 + 分录 0 转账),但这是我自己定的,模型没给范式。**火上浇油**:world-model 里"穿越"这个词**同时**被写在"分支(重生/穿越)"和"作用域(穿越/无限流)"两处说明下,连"带着前世记忆/主世界见闻"这个例子也两处都挂——读起来像模型自己都没定死穿越到底是换 branch 还是换 scope,留给实例化的人各自解释,容易两本书两套记法。

### (附)摩擦 #5 —— "等级"这个词在账本里,但修仙的"等级"其实是设定+角色+账本三方合成。
模型把"等级"列进数值账本(积分/货币/等级/库存)。可修仙的"等级"=境界,它的**阶梯定义在设定**、**当前所处一级在角色状态**、**突破那一下在时间线**、**系统另算的签到天数/战力评定才真在账本**。照搬"等级=账本字段"会误导,实例化时我得把一个"等级"直觉手动拆到四个地方。到底哪个 kind 拥有"等级",建议模型对经营/系统流的"账本等级"和修仙的"境界等级"明确分家。
