| 位置 | 已有能力 | 本轮缺口 |
| --- | --- | --- |

| `v0/src/layout.ts` 的任务登记、创建与枚举 | 一部作品可以保存多条任务登记，每条有独立产物与会话目录 | 缺少面向页面的任务列表与明确任务选择 |

| `v0/src/local-contract.ts` | 页面命令和运行占用已经携带作品与任务身份 | 页面快照未包含可选择的任务摘要与任务新建命令 |
| `v0/src/local-server.ts` | 新建作品、读取作品状态、任务命令和明确稿件读取 | 读取状态只按作品；没有任务新建和任务枚举入口 |
| `v0/ui/app.ts` | 作品切换、阅读、输入保存、活动任务提示 | 查看选择与输入、稿件引用、阅读位置只按作品保存；运行提示也仅比较作品 |
| `v0/src/local-app.ts` 的 `recover` | 启动时尝试继续中断的资料同步 | 仅检查每部作品最新任务；新建空白任务后可能遮住真正待恢复的旧任务 |
| `v0/src/local-records.ts` | 任务对话、产物、决定及执行状态可分别读取；定稿结合正式正文校验 | 需要在任意选定任务上读取，并防止相同 `draft_1` 等局部身份跨任务串用 |
| `v0/src/guard.ts` 的 `contextReadZones` | 隔离其他作品和私有运行数据，但 Context 可读取整部作品目录 | 新会话不等于检索隔离；默认读取与搜索仍可能混入同作品其他任务的初稿与废案 |

## 已有状态与边界

- 执行状态为 `idle`、`running`、`stopping`、`stopped`、`interrupted`、`failed`。待作者决定、稿件检查情况、正文定稿及作品待同步是独立事实，不能合并成一个“任务完成”状态。
- 正式资料与待同步章节归作品；临时对话、未定稿产物、作者决定与执行归任务。新的任务不意味着新的作品或新的章节。
- 同一服务已有一个活动作者任务，完整停止已包含 Context 和子 Agent。新增同作品任务后，页面比较目标必须从“是否另一作品”改为“是否另一任务”。
- 正式资料可能被同作品其他任务更新；返回旧任务后仍需按当前正式内容校验写入、定稿及作者确认，不恢复作品旧快照。
- 同步清单包含当前定稿正文的摘要指纹；重新定稿后旧清单会被现有门禁拒绝。增加任务入口后，还需把同步责任与当前正式版本对应起来，不能仅凭最新任务或一条历史定稿记录选择承接者。

## 复用的验证依据

`v0/test/session.test.ts` 已验证新任务不继承旧对话、继续任务复用登记会话。`v0/test/local-app.test.ts` 已覆盖真实本机应用边界下的写作、作者确认、运行占用、停止与恢复。继续在模型响应边界替换回复，复用真实服务、会话、工具与文件保存。
