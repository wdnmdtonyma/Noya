# 写作任务新建与切换 · 旅程走查

作者已确认：新建独立任务、返回旧任务继续；沿用页面结构、单任务执行及作品正式资料，先交付 PRD 和 spec。本稿把这些决定展开为完整旅程，供独立审查与最终确认。

## 1. 进入与新建

作者进入作品后，看到上次查看的任务；没有选择记录时回到最新创建的有效任务。保存的选择已经失效时说明情况并让作者重选，不静默改投另一任务。原来没有任务的作品仍自动获得第一个任务。

在当前任务标题旁提供轻量的任务入口，包含“新建任务”和已有任务选择。点击新建后，成功保存才切换到新的空白任务，不要求先命名，不调用模型、不写正文、不定稿，也不清空旧任务。失败留在原任务并保留输入；同一次创建因重复点击或响应丢失而重试，返回同一个任务。

空白任务以创建时间及可区分的短标识识别，有首条作者消息后以其摘要识别。任务仍然允许从讨论或查询开始，不与一章一一对应，不在交稿或定稿后自动新建。

## 2. 任务隔离与返回

新任务使用当前作品的正式资料和定稿正文，开始独立的 Context 对话。旧任务的消息、初稿、修改引用、待确认问题和未发送输入留在原任务；本轮不提供复制任务或把旧初稿带入新任务的操作。

任务选择项显示可区分的名称、创建时间与真实状态；按创建时间倒序排列，不因查看而移动。切回旧任务后，可以阅读原稿、继续讨论、提出修改、定稿或回答其待决定问题，所有动作都明确指向这个任务。若正式资料在其他任务中更新，旧确认或定稿条件已经过期，就先显示变化并重新确认，不套用旧授权。

切换作品后再回来，恢复该作品上次查看的任务；输入、稿件引用和阅读位置按作品与任务分别保存。首次升级时，已有任务原样出现在选择入口；旧版仅按作品保存的界面状态只迁移给它原先指向的最近任务一次。无法确认归属时保留旧内容，由作者确认任务，不按最新任务猜测。

## 3. 运行中的新建与切换

任务 A 执行时可以新建或查看任务 B；这只创建空白记录或改变查看对象，不停止 A，也不在 B 调用模型。B 保留输入并说明 A 仍在执行，提供返回 A 与明确停止 A 的入口。A 停稳或正常结束后，作者可在 B 发送。

这条规则同时适用于同作品和跨作品。晚到的 A 回复、稿件与状态归 A。A 等待作者决定且没有执行时，可执行 B；A 的问题保留，之后回到 A 再回答。B 执行期间，不能通过回答 A 的问题或定稿 A 的稿件启动另一个任务。

## 4. 待同步与正式资料

资料待同步属于作品，不能通过新建任务绕过。作者仍可创建、查看或讨论新任务；需要安排写手生成或重写正文时，页面说明待处理章节并提供回到其同步任务的入口。纯措辞修正沿用已有能力，保存后的稿件仍不是正式正文。

正常的新定稿在原任务中同步。原任务有未回答的冲突或被作者停止时，必须回到原任务处理，不能把决定复制给新任务。完成后作者返回新任务并明确继续之前的写作要求；不暗中启动新任务。

旧版本或 CLI 数据没有可定位的同步任务时，说明只能找到待同步章节；作者明确选择在当前任务继续同步后，该章的同步归当前任务，直到同步完成。其他任务及重启后均返回此任务处理，不能再次把它当作无人承接。Context 读取当前定稿正文和正式资料重建清单，不继承其他任务的临时讨论或确认。资料损坏时显示错误，不用新建任务掩盖问题。

若在其他任务中明确重新定稿同一章，先说明替换正式正文；新的定稿使旧同步清单和旧决定失效，同步转由此次定稿的任务承接。旧任务仍保留历史记录，但不继续执行针对旧正文的同步。

## 5. 重开与中断

刷新或重新打开页面恢复上次查看的具体任务，并显示本机服务的真实活动任务。仅查看旧任务不重新打开或中断其 Agent。

程序退出后，恢复记录，旧执行显示中断；需要继续时按保存内容重新安排。未完成同步的自动恢复查找真正执行同步的任务，不因后来创建的空白任务而换对象。待作者决定或明确停止的任务不自动恢复。

新建、切换、阅读、运行及继续在多个标签页中仍以明确任务身份核对。同一个任务中的重复请求不重复执行，另一标签页创建新任务不让当前标签页自动跳走。任务记录损坏时保留原数据，在列表标出并允许查看其他健康任务；不静默切成另一个任务执行。

## 6. 本轮功能

- 新建当前作品的独立写作任务。
- 选择和继续已有任务。
- 在任务之间隔离输入、阅读、决定与实际执行。
- 恢复具体任务，并保留作品级待同步门禁。

测试边界沿用作者此前确认的真实页面、本机应用与写作运行时；自动化仅替换模型响应。新增验收重点是同一作品中两个任务之间的往返，而非重复建设既有写章链路。
