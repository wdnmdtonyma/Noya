# 写作任务新建与切换 · 独立审查记录

日期：2026-10-04。模式：单个独立审查者。

## 旅程审查

收到两项产品路径遗漏和一项工程隔离意见，全部采纳：

| 问题 | 处理 |
| --- | --- |
| 旧数据在当前任务承接同步后，没有持久归属 | 记录承接任务；后续切换和重启返回该任务，保留其停止及待决定状态 |
| 待同步门禁只写了新章，未覆盖返回旧任务重写 | 将提示条件扩展到安排写手生成或重写正文；同步后由作者回原任务明确继续 |
| 独立对话仍可能通过通用搜索读到旧任务材料 | 在 spec 中加入任务读取隔离，以及直接读取、递归检索两种验收 |

另补充当前定稿版本变化时同步归属的处理：替换定稿后旧清单与决定失效，由新定稿的任务承接。此行为是现有定稿指纹校验在多任务中的延伸。

问题：同步归属若只用于页面导航，非负责任务的 Context 仍可直接调用同步工具，绕过原任务的停止或待决定状态。

修正：保存同步清单和应用同步均校验当前正式版本的负责同步任务，应用阶段在写入锁内复核；新增非负责任务直接调用工具的验收。另明确相同正文在另一任务重新定稿也属于新的定稿动作，不能只凭正文相同认定旧确认仍有效。
