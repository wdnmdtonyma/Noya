# Noya 本地 Agent 界面风格

## 证据与适用范围

当前 v0 是 CLI，没有可沿用的正式图形界面。本次依据既有 Noya 原型提取视觉语言；原型中的写作台、章节导航和编辑器不代表本次的信息架构。

- `docs/prd/noya-mvp/canvas/tokens.css`：完整复用暖纸、墨色、朱砂主色和墨绿状态色；没有新增变量。
- `docs/prd/noya-mvp/canvas/shell.css`：参考按钮、列表激活态、细边框、轻阴影和文字层级。
- `docs/prd/noya-mvp/canvas/pages/04-d-three-column.html` 前部样式：仅参考区域分隔和紧凑侧栏，不复用其编辑器居中的三栏骨架。
- 没有用户参考截图；以下新布局来自本次已确定的任务范围，尚不是上线界面规范。

## 本次布局

用户已认可六段旅程；页面沿该旅程重新收敛。业务流程沿用 v0，旧版的管理侧栏不再作为布局约束。

- 顶部：品牌、当前作品与轻量切换入口，选择已有作品或直接新建空白作品。
- 主区：该作品最近任务的对话，底部输入。执行过程默认短摘要，展开后显示 Context、Writer、Reviewer、Sync Checker 的具体分工。
- 阅读区：点击交稿消息打开全文，显示所属作品、章节、版本和检查结论，提供提出修改和定稿当前版本。
- 资料写入确认、关键创作分歧与同步冲突在对话内呈现；执行中切换作品时显示原任务与返回/停止入口。
- 窄屏将阅读区覆盖在任务上，保留返回路径；没有独立任务管理、资料目录、审计、盲比或模型设置页。

## 可复用的视觉模式

- 背景 `--color-bg`，侧栏与面板 `--color-surface`，输入框和小浮层 `--color-surface-raised`；以 1px 暖灰边框分区。
- 普通文字用系统无衬线字体；任务正文可用 15px，辅助信息 12–13px。宋体仅用于小说产物预览，路径或代码用等宽字体。
- 朱砂 `#a33f32` 用于主要动作和选中任务，墨绿 `#2f6558` 用于执行过程的可靠状态。警告与失败使用各自语义色，同时写明状态。
- 列表项用 8px 圆角、浅色激活底、紧凑行距；卡片用 12px 圆角。大区域平铺，只给输入框、产物入口和浮层轻阴影。
- 按钮延续实心主按钮、细边框次按钮、透明工具按钮；避免同屏多个醒目的主操作。
- 输入框全边框，聚焦时使用 `--focus-ring`。空间以 8/12/16/24px 为主，面板头部标题左对齐、动作靠右。
- 对话直接排在阅读区；执行步骤默认短摘要，详情按需展开。完成后给出结果和可点击产物，避免每一步都成为大卡片。
- 交互过渡复用 120–200ms 时长；尊重系统减少动态效果设置。空状态给一句说明和一个可行动入口。

## 验证

设计稿使用固定样稿，不连接真实模型与作品。桌面与窄屏的浏览器走查结果见 PRD 包中的 `design-validation.md`。
