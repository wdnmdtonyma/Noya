# 收敛后设计稿 · 验证记录

日期：2026-10-04。页面：`http://localhost:54852/p/01-tasks`。

## 本次改动

保留一个任务页，顶部选择或新建作品。各作品分别显示自己的最近任务、未发送输入与稿件。正文从交稿消息打开，桌面可边读边看对话，窄屏采用可关闭的阅读层。

执行摘要可展开查看 Context、Writer、Reviewer 和 Sync Checker 的分工。方案检查自动推进；作者只处理资料写入、方向调整、正文定稿和同步冲突等具体决定。原来独立的任务管理、内容目录、盲比、审计和模型设置入口已移除。

## 浏览器走查

通过 playwright-cli 在独立的原型浏览器配置中验证，没有操作真实作品。

| 路径 | 结果 |
|---|---|
| 无作品 → 新建 → 空白讨论 | 通过；新建无需名称表单，讨论不启动写手 |
| 讨论资料 → 作者确认 → 写入 | 通过；确认前演示资料不变，确认后才记录 |
| 明确写作 → 自动方案检查 → 写稿与检查 → 交稿 | 通过；没有逐章批准方案按钮，执行中刷新后能恢复演示运行 |
| 阅读 → 提出修改 → 新稿 → 定稿 → 同步 | 通过；修改带所读稿件引用，新旧稿分别保留 |
| 打开较早版本 → 指定该版定稿 | 通过；已有第 2 版时指定第 1 版，保存对象仍为第 1 版，未误用最新版 |
| 运行中 A → 查看 B → 返回 A | 通过；B 的内容与输入独立，A 运行期间不能在 B 发起执行 |
| 在 B 明确停止 A，再在 B 开始 | 通过；A 保存的稿件保留，停止完成后 B 可以执行 |
| 同步失败 → 正文保持定稿 → 继续同步 | 通过；失败不清空定稿，恢复后分别更新同步状态 |
| 同步冲突 → 按正文更新／保留原设定 | 两条分支通过；作者决定前保持待同步，保留原设定时只同步其余有依据的变化 |
| 改变写作方向 | 通过；确认前不重新派写手，确认后进入新方案流程 |
| 模拟程序退出 → 恢复记录 → 重新安排执行 | 通过；旧执行显示中断，恢复后使用所属作品的内容 |
| 页面刷新与跨作品输入保存 | 通过；恢复所选作品、稿件、定稿状态与未发送输入 |
| 桌面及 390px 窄屏 | 通过；阅读、切换浮层无横向溢出；窄屏阅读时底层任务区不可获取焦点，关闭后恢复 |
| 键盘与减少动态效果 | 通过；作品选择支持键盘，Escape 关闭浮层和阅读区；减少动态效果时停用动画 |

初次长脚本在后段因浏览器会话关闭而中止；将同步失败与两种冲突选择、恢复、方向确认和键盘场景拆成短脚本后均通过。一次等待失败源于测试精确匹配忽略了提示中的附属文字，核对实际页面后修正定位。未把这两次中止记为产品验证通过。

## 验证边界

这是固定样稿的可点击设计原型，不是已接入模型的 Web 应用。对话采用有限的演示分支，不支持任意自然语言生成真实小说；执行进展用演示计时驱动。此记录只证明界面路径与状态交互，真实模型质量、流式事件、整体停止、业务持久化和断线重连仍需正式页面接入后验收。
