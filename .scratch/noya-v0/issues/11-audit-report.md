# 11 — 审计报告

**What to build:** 评估者运行 `noya audit <作品> [任务]`（缺省为最近一个写作任务），得到一份 Markdown 报告，保存在该任务目录中，并在终端打印路径。报告从 Context 会话、全部 Subagent 会话、Subagent 登记与任务产物中统计：各工具调用次数；被拒绝的调用及原因；加载了哪些 Skill；各类产物的版本数与每份同步清单的核对次数；每份初稿是否经过检查员检查、被定稿或最后交出的初稿的四项结论；各角色 token 与耗时；提交产物前就结束的 Subagent 轮次。评估者据此判断 Context Agent 是否跳过了方案检查或正文检查、门禁拦住了多少越权。

契约详见 `.scratch/noya-v0/spec.md`："审计"、"校验与错误约定"（`[拒绝]` 前缀）、"Subagent"中的登记内容。
