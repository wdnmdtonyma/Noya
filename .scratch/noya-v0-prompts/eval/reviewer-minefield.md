# 检查员埋雷测试（P3）

同一份 Brief + Pack + 初稿，交给新检查员检查三次，按"答案"统计。

送检方法（只用现有契约）：在一个新写作任务中，让 Context Agent 用下方 Brief 与 Pack `save_package` 并派出写手；写手 `submit_draft` 后，用 `edit` 把写手的初稿文件整体替换为下方初稿，`save_revision` 得到埋雷稿的 `draft_id`，再 `spawn_subagent({ role: "reviewer", draft_id })` 三次。`chapter_id` 用未定稿的 `chapter_mine`，避免与已定稿章节冲突。运行前测试作品中需已有下列正式资料 ID（S1 聊出的书即可满足，缺哪个就补写）：`lu_zhao`、`lu_ying`、`library_liuyun_step`、`library_husheng_jade`、`houshan_valley`。若 S1 的实际 ID 不同，替换 Pack 来源行与 Brief 即可，摘录文本不变。

## Brief

```json
{
  "schema_version": 1,
  "id": "brief_ch001_mine",
  "chapter_id": "chapter_mine",
  "mode": "write_chapter",
  "intent": "陆萤在后山失踪，陆昭第一次为了妹妹主动闯入险地。",
  "requirements": [
    "陆昭在毒瘴谷口捡到陆萤的药篓。",
    "陆昭独自进入谷中，与看守谷口的石傀儡交手后脱身。"
  ],
  "constraints": [
    "本章不揭示是谁把陆萤带进谷中。"
  ],
  "ending": "陆昭在谷中看到妹妹留下的记号，决定继续深入。",
  "creative_scope": [
    "可以安排与石傀儡交手的具体过程。"
  ],
  "leave_open": [
    "石傀儡的主人是谁。"
  ]
}
```

## Pack

```markdown
## 陆昭

来源：lu_zhao

青岩宗杂役，生性谨慎，遇事先求自保，从不主动惹事。父母早亡，陆萤是他唯一的亲人。
掌握：流云步（入门）。持有：护身玉一枚，随身佩戴。

## 陆萤

来源：lu_ying

陆昭的妹妹，常去后山药田采药。随身带一只竹编药篓。

## 流云步

来源：library_liuyun_step

轻身步法。入门者可在短时间内大幅提升脚力，连续施展不宜超过十息，超过后双腿抽筋，需歇息片刻。

## 护身玉

来源：library_husheng_jade

效果：受到金铁或拳脚之伤时自动亮起，替佩戴者挡下一次，挡下后碎裂。
限制：不能防御毒雾、瘴气等非外力伤害。

## 毒瘴谷

来源：houshan_valley

青岩宗后山深处的山谷，常年有毒瘴，宗门禁止弟子入内。谷口有石傀儡看守。

## 尚未确定

来源：无

石傀儡由谁放置、听命于谁，作者尚未决定。
```

## 初稿

```markdown
# 第一章 谷口

天擦黑的时候，陆萤还没回来。

陆昭在药田边站了一炷香，又站了一炷香。往常这个时辰，她早该背着药篓从坡上下来，远远喊一声"哥"。他沿着她常走的小路往后山找，越走越偏，脚下的石子渐渐带了潮气。

毒瘴谷口立着那块刻着"禁"字的石碑。碑脚下，倒着一只竹编药篓，篓里的车前草撒了一地，还是新鲜的。

陆昭蹲下去，把药篓扶正。篓沿上缠着一截红绳，是他去年在集上给她买的。

他知道自己该回去报给执事。他一向是这样的人，遇事先退半步，从不往前凑。可他抬头看了一眼谷里翻滚的灰雾，想起爹娘下葬那天，陆萤攥着他袖子说"哥，就剩咱俩了"。他把药篓背到自己身上，往谷里走。

灰雾迎面扑来，呛得他眼前发黑。胸前的护身玉亮了一下，雾气便在他身前一尺处散开，再近不得身。

刚过石碑，两尊石傀儡从雾里转出来，关节咯吱作响，一左一右封住去路。陆昭屏住呼吸，运起敛息术，把自己的气息压得几近于无。左边那尊石傀儡的头颅转了半圈，没有发现他。

右边那尊却径直扑来。陆昭抽出柴刀格了一下，虎口震得发麻，刀刃崩了个口子。他脚下一错，流云步施展开，贴着谷壁绕到它身后，又一口气冲出二十余丈，才敢停下。

他扶着一棵枯树喘气，余光瞥见石傀儡背上刻着一枚小小的"周"字。是周执事的傀儡。

雾淡了些。前方一块青石上，有人用炭条画了一朵歪歪扭扭的桂花。那是陆萤的记号。

陆昭握紧了拳，继续往谷里走。
```

## 答案（不给检查员看）

| # | 埋入的问题 | 期望 | 依据 |
|---|---|---|---|
| 1 | "是周执事的傀儡" 揭示了傀儡主人 | `violation` / `requirements` | Brief `leave_open[0]`；或 Pack"尚未确定"不可引用（来源为无），应引 Brief |
| 2 | 护身玉挡下毒瘴 | `violation` / `ability_rules` | `library_husheng_jade`："不能防御毒雾、瘴气等非外力伤害。" |
| 3 | 运起敛息术 | `needs_verification` / `possessions_and_abilities`；**不得**为 violation | Pack 未提及，不矛盾 |
| 4 | 谨慎的陆昭独自闯谷 | 不应有 `violation`；`character_motivation` 应为 `passed` | 正文给出红绳、爹娘下葬时的话等处境支撑；Pack"陆萤是他唯一的亲人" |

附带观察（不计入目标，记录即可）：柴刀未在 Pack 持有物中列出，属于 `creative_scope` 内的交手细节，最多为待核实；流云步"一口气冲出二十余丈"是否被当作超过十息而判 violation——十息内跑二十余丈并无矛盾，判为 violation 视为误判。

统计：#1、#2 每次检出；#3、#4 被判 violation 的次数；`save_review` 被拒次数及原因。
