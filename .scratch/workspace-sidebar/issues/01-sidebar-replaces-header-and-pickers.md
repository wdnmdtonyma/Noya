# 01 — 展开侧栏替换顶栏和两个选择弹窗

**What to build:** 任务页左侧常驻一条展开的侧栏，取代顶栏、作品选择弹窗和任务选择弹窗。

侧栏从上到下是：
1. 品牌"Noya / 让故事继续"和收起按钮。收起按钮先占位，收起功能由 02 实现。
2. 当前作品卡片：首字封面、作品名、"N 个写作任务"。点开后在卡片下方弹出作品列表，列表里能新建作品。
3. 新建任务按钮，沿用现有的创建去重。
4. "写作任务"分区标题和总数。
5. 本作品的任务列表：每行一个状态圆点、任务名和一行状态，当前任务高亮并带左侧竖线，点一行直接切换。
6. 底部的本机连接状态。

主列顶部保留断线提示和执行中提示。任务标题上方显示"作品名 / 写作任务"。

规格见 `../spec.md`，User Stories 1–26、56–61，实现决策第 1、2、5 节。

**Blocked by:** None — can start immediately.

**Status:** ready-for-human

- [x] 纯推导层测试覆盖任务行状态文字的全部优先级：记录损坏 → 执行中 → 正在停止 → 待决定 → 执行失败／已中断／已停止 → 创建时间。
- [x] 纯推导层测试覆盖色调，以及断线时一律为 offline。
- [x] 纯推导层测试覆盖跳动圆点：只给与执行引用一致、且已连接的任务。
- [x] 纯推导层测试覆盖作品卡片的任务数，以及未选择作品时显示"选择作品"。
- [x] 顶栏、作品选择弹窗和任务选择弹窗从页面移除。新建作品、新建任务、"正在保存新任务…"和"确认上次创建结果"在侧栏中照常可用。
- [x] 作品列表标出当前作品、执行中的作品和读取错误。Escape、点外部或再点卡片都能关闭，关闭后焦点回到卡片。
- [x] 记录损坏的任务行不可点击；断线时"新建任务"不可点击。
- [x] 任务很多时只有任务列表滚动，品牌、作品、新建任务和连接状态保持不动。
- [x] 从侧栏切换任务时，按任务保存的输入、阅读位置和展开状态照常保存与恢复。切换时自动关闭子任务详情、子任务列表和作品列表。
- [x] 轮询刷新只更新变化的侧栏节点，任务列表的滚动、焦点和打开的作品列表不受影响，页面不抖动。
- [x] 现有本机应用测试、写作任务测试和推导层测试全部通过。
