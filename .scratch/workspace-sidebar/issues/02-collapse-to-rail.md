# 02 — 桌面收起为窄栏、提示、快捷键与保存

**What to build:** 桌面上，侧栏可以在展开和只留图标的窄栏之间切换。

切换方式：
- 点收起按钮；
- 点窄栏里的品牌位，悬停时品牌标记换成展开图标；
- 按 ⌘\，非 Mac 上按 Ctrl+\。

所有图标共用同一列图标槽，收起时只裁宽度，图标不重排。窄栏里：
- 作品卡片只留封面，作品列表改为在侧栏右侧弹出；
- 新建任务只留加号；
- 任务列表隐藏，换成任务图标。图标上的角标提示执行中或失败，点开在侧面弹出任务列表，底部有"新建任务"。

窄栏中悬停或用键盘聚焦任一图标，旁边浮出提示。收起状态是全局偏好，保存在本机，刷新后直接显示保存的状态，不播放动画。

规格见 `../spec.md`，User Stories 27–45，实现决策第 2、3、4 节。

**Blocked by:** 01 — 展开侧栏替换顶栏和两个选择弹窗

**Status:** ready-for-human

- [x] 纯推导层测试覆盖窄栏角标：执行中优先于失败，断线时不显示执行中，两者都没有时不显示角标。
- [x] 纯推导层测试覆盖提示内容：作品名、"N 个 · 当前「任务名」"、断线时新建任务附注"连接恢复后可用"、收起和展开按钮附快捷键。
- [x] 收起和展开过程中图标的水平位置不变，只有宽度和文字透明度变化。
- [x] 展开状态下，任务图标是不可聚焦的分区标题；窄栏状态下它是可聚焦按钮。收起按钮在窄栏中隐藏且不可聚焦，品牌位在展开时不可聚焦。
- [x] 侧面弹出的任务列表打开时，焦点落在当前任务上。Escape、点外部或再点图标都能关闭，关闭后焦点回到图标。切换形态、任务或作品时自动关闭。
- [x] 提示只在桌面出现。窄栏中对所有图标生效；展开时只对收起按钮和被截断的任务名生效。悬停约 420ms 出现，连续扫过时立即切换，键盘聚焦时立即出现。
- [x] 焦点在侧栏里时用快捷键切换形态，焦点会落到新形态下的展开或收起按钮。
- [x] 刷新、切换任务和切换作品后，收起状态都保留，首次加载不播放宽度动画。本机存储不可用时默认展开，不报错。
- [x] 打开子任务详情或成果阅读时，侧栏形态不变。
