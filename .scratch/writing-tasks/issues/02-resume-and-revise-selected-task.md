# 02 — 回到旧任务继续写作与修改

**What to build:** 作者切回非最新写作任务，恢复原讨论、稿件、输入和阅读位置，继续原目标或修改明确版本；任务之间共享当前正式资料，但不能通过读取和搜索带入其他任务的临时材料。补齐对应原型交互，并贯通真实页面、任务工具与保存结果。

**Blocked by:** 01 — 新建并切换独立写作任务。

**Status:** ready-for-human

- [x] 可点击原型与真实页面都能从任务列表返回旧任务，阅读它的稿件、引用指定版本并发送修改要求；不自动把引用替换为该任务或其他任务的最新稿。
- [x] 输入、引用的稿件、阅读对象与滚动位置按作品和任务分别保存。A、B 拥有相同局部稿件编号时，读取、修改、决定与定稿命令仍使用完整归属，错配和跨作品引用被拒绝。
- [x] 返回 A 后继续使用 A 的 Context 记录、作者目标和保存材料，回复与修改结果落在 A；B 成为最新任务不影响此行为。旧 Writing Agent 无法继续时说明情况并按现有流程重新安排，不把历史记录显示为仍有活跃写手。
- [x] 未回答的问题和确认留在提出它们的任务。回到旧任务不会还原作品的历史正式资料；其他任务已更新相关正式内容或决定对象时，旧确认不能直接写入，必须说明失效并重新呈现具体内容。
- [x] 新任务的通用读取、列举与搜索只能返回本任务工作材料、本作品正式资料和流程说明。直接读取其他任务、从作品根递归搜索均不能返回其讨论、废案、未定稿正文、检查和同步提案；不能仅靠提示词实现。
- [x] 隔离后仍能查询当前正式资料、读取当前任务稿件，并正常执行现有角色工具。需要继续别的任务的未定稿内容时回到该任务，不增加跨任务导入功能。
- [x] 切换时遇到晚到正文读取、快照或发送结果，不覆盖当前任务的阅读内容或输入；发送完成只清理原任务中已发送的内容，不清除作者后来补写的文字。
- [x] 在真实本机应用与写作流程中，仅替换模型响应，验收两个任务具有相同局部稿件编号、返回旧任务修改指定版本、旧 Writer 不可恢复和正式资料更新后确认过期；核对实际产物与写入目标。
- [x] 用旧任务的唯一临时标记验证直接读取与递归搜索均不能向新任务泄漏，同时证明正式资料和当前任务材料仍可读；在浏览器演示旧任务继续、稿件引用和阅读位置恢复。跨任务重新定稿后的同步归属由 04 完成。
