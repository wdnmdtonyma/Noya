# 01 — 新建并切换独立写作任务

**What to build:** 作者在当前作品的任务入口新建一个空白写作任务，开始独立讨论、查询正式资料，并能选择已有任务查看或继续对话。沿用现有页面布局，先补齐可点击原型中的任务入口、任务列表与空白态，再接入真实本机服务和保存能力。以《写作任务新建与切换》规格为依据，复用现有写作流程。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

- [ ] 先调整现有任务入口，使读取、发送与恢复始终指向明确的作品和任务；新任务出现后，非最新任务仍可继续原对话。只读查看不启动模型、不重新打开活跃运行时、不把仍在执行的 Agent 标成中断；CLI 原有新建与继续最近任务的行为保持兼容。
- [ ] 在原有布局上提供可点击的新建、任务选择与空白态原型，并在真实页面实现同样的操作路径；入口只列当前作品的任务，不新增独立管理页面或正文编辑器。
- [ ] 新建不要求先填名称或章节，不创建新作品、不自动发送消息或安排写稿；保存成功后才选中新任务。明确失败时留在原任务并保留输入，结果未知时用原请求确认结果。
- [ ] 同一次创建的重复点击、并发请求、响应丢失和服务重启后重试均返回同一任务；两次明确的新建动作产生不同任务。创建请求与任务的对应关系持久保存，未成功登记的目录不显示为健康任务。
- [ ] 从未有任务的作品首次进入时得到一个空白任务，并发进入不会重复创建；已有任务直接可见，不要求作者重新建立任务。
- [ ] 列表显示可区分的名称、创建时间、执行状态与待作者决定情况。名称取首条作者消息开头，空白任务显示“新任务”、时间和短标识，不调用模型命名；按创建时间倒序排列，同时间稳定排序，查看不改变顺序。
- [ ] 新任务能查阅本作品当前正式资料和定稿正文，拥有独立对话与产物；旧讨论、废案、初稿、决定和通知不自动进入新任务，旧任务记录保留。通用读取与搜索的完整隔离由 02 验收。
- [ ] 当前选择与未发送输入按作品和任务分别保存，切换前保留原输入，新任务从空白开始；创建或读取的响应晚到时，若作者已切换，不强制跳回或覆盖当前输入。其他标签页创建任务不改变本页正在查看的任务。
- [ ] 选择无效任务或错配作品与任务时明确报错，不将操作改投最新任务；单条任务读取失败单独标识，健康任务仍可进入。新建和查看不清除作品待同步事实，也不绕过已有单任务执行限制。
- [ ] 在真实本机应用、写作会话、工具和存储边界验收，仅替换模型响应；覆盖创建去重与重启后重试、同作品两个任务独立讨论、返回非最新任务、错配身份和单条损坏记录。通过浏览器实际演示创建、切换与输入保留，并记录结果。
