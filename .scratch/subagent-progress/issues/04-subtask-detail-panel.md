# 04 — Sub 详情面板与 Sub 的实时过程

**What to build:** 作者点击子任务卡片，在任务页右侧打开该 Sub 的详情面板，主信息流留在左侧，仍然可读、可输入：
- 窄屏时面板全屏打开；宽屏时高度固定，内容独立滚动。
- 右侧同一时间只显示一项，打开另一项会替换当前内容。

面板内容按时间排列：Context Agent 派发的要求全文 → 这次执行的过程与成果 → 追加的要求 → 下一次执行……

本机应用同时开始订阅每个活跃 Sub 的会话，卡片和面板显示 Sub 的当前动作；面板底部显示这次执行的"正在处理"和用时。
