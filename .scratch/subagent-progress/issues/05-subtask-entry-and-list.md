# 05 — 输入框上方的子任务入口与列表

**What to build:** 输入框上方有一个不随信息流滚动的子任务入口。

入口文案按以下优先级决定：
1. 进行中 Sub 的卡片还在屏幕上时，只显示"子任务"和总数。
2. 卡片已滚出屏幕、且只有一个 Sub 进行中时，显示"writer-2 正在修改 chapter-1.md"。
3. 多个进行中时，显示"N 个子任务进行中"；有失败时追加"· N 个失败"。
4. 没有进行中、但有失败时，显示"N 个子任务失败"。
5. 都结束后，显示"子任务"和总数。

点击入口，在输入框上方展开列表：
- 不遮罩页面，背景和输入仍可操作。
- 再次点击、点关闭、按 Escape 或点外部都会收起。
- 选中一行，打开该 Sub 的详情面板。
