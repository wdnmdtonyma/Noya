# 03 — 轮次收起、实时状态与发送/停止合一

**What to build:** 信息流按"作者每次发言 → Context Agent 这一轮处理"组织。

**进行中的一轮：**
- 完整展开，底部有一行"正在处理"和本轮已用时长。
- 停止过程中显示"正在停止"。

**结束的一轮：**
- 收成"已处理 X 秒"，超过一分钟写作"X 分 Y 秒"。
- 收起时只保留子任务卡片、Context Agent 的最后一条回复和非常规事件。
- 以失败、中断或停止结束的最后一轮收为"处理 X 秒后失败／中断／停止"，带相应颜色，并且不保留出事前的最后一条回复。

**发送与停止共用一个按钮位置：**
- 本任务执行中、输入为空时显示停止；一输入文字就变回发送。
- 执行中发出的补充要求交给 Context Agent 在当前执行中处理。
- 另一条任务正在执行时，本任务可以输入但暂不能发送，并说明是哪条任务在执行。

**Blocked by:** 02 — 子任务卡片与每次执行的成果

**Status:** ready-for-agent
