# 08 — Context Agent 每轮收尾回复

**What to build:** 一轮里的子任务都结束、Context Agent 不再等待后台通知时，它用一条回复告诉作者本轮做出了什么，以及需要作者决定的事。例如："第 2 版已通过检查，万舟只观察变化，没有解释刻痕来源。满意就可以定稿，或者告诉我哪里要改。"

收起的一轮保留这条回复，作者回看时一眼知道结果和下一步。仍在等待后台通知时，Context Agent 照旧简短告知正在进行。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] Context Agent 的系统提示增加这条要求：
  - 写明触发时机：没有仍在运行、需要等待的子任务；
  - 写明回复包含：本轮结果、需要作者决定的事；没有要决定的事就不硬凑。
- [ ] 不在代码中强制、检测或代写这条回复。
- [ ] 不改变现有约束：派出后告诉作者正在进行然后结束本轮；不反复查询状态；普通讨论不开始写作。
- [ ] 用现有提示评测场景跑一次，确认写作流程、检查和同步行为没有退化。结果和至少一个真实收尾回复样例记在本文件 `## Comments`。
