# 02 — 进入作品并与 Context 对话

**What to build:** 作者在页面中创建或选择作品，进入其最近任务，与 Context Agent 真实讨论、查询资料，并在明确确认后写入正式资料。每部作品保留自己的记录和未发送输入。

**Blocked by:** 01 — 搭好本地应用框架与页面骨架。

**Status:** ready-for-agent

**Implementation:** completed · 2026-10-04

对应规格：Noya 本地 Agent 任务界面 MVP；用户故事 1–15、47，以及通用错误与身份边界。

- [x] 无作品时可直接创建第一部作品并进入空白任务；不要求先填书名、题材或设定，未命名作品具有稳定且可区分的名称。
- [x] 单作品直接进入最近任务；多作品恢复有效的上次作品，否则提供选择入口；已有作品没有任务时创建首个任务。刷新、普通发送和重新进入不重复创建作品或任务。
- [x] 空闲时可以切换作品，当前作品标识始终可见；对话、资料和未发送输入分别保存。记录损坏或失效时说明具体对象，不静默替换作品。
- [x] 页面发送消息经过共享 ModelRuntime 与 openWritingSession，运行真实 Context 会话及工具；收到实际回复并保存作者和 Agent 记录。读取页面状态不重新打开运行中的会话，不把查看当成进程恢复。
- [x] 普通讨论不会自动派 Writing Agent；查询结果能够区分正式事实、未来计划、建议与未知。模型遵循意图的表现还须在最终真实验收中确认。
- [x] 写入资料前展示具体变更；作者的回答及确认对象进入所属任务记录，再经现有工具门禁执行。拒绝、取消或过期确认不写入正式资料。
- [x] 建立服务端单作者任务占用：同服务的两个标签页不能同时在不同任务发起执行，重复发送不会重复启动；本票先完成基础约束，运行中跨作品查看与整体停止由 06 完成。
- [x] 请求校验作品及任务归属，不允许用浏览器传入的任意路径读取作品；迟到的回复不能归入另一作品。
- [x] 未登录、配置不完整、模型失败或保存失败时，页面明确说明问题并保留已有记录；不新增设置页或自动切换模型、供应方与计费来源。
- [x] 使用真实页面、服务、临时作品和现有运行时，仅替换模型响应，验证空白讨论、资料查询、确认前后保存结果、空闲切换和单任务拒绝；现有类型检查与相关回归通过。
- [x] 作品入口和任务输入支持键盘及窄屏使用；不增加作品管理或历史任务管理页面。
