# 07 — 重连、重启后继续工作并完成真实验收

**What to build:** 作者关闭或刷新页面后接回仍在运行的任务；本机程序退出后找回记录和成果，看见真实中断状态，并继续修改或同步。最后在真实模型下完成包含多作品的完整日常写作旅程。

**Blocked by:** 04 — 针对明确版本修改并复查；05 — 指定版本定稿并同步资料；06 — 运行中切换作品与整体停止。

**Status:** ready-for-agent

**Implementation:** completed · 2026-10-04

对应规格：Noya 本地 Agent 任务界面 MVP；用户故事 48–52，及完整旅程验收。此票实现实际恢复行为，不是集中补写前六票测试的收尾票。

- [x] 仅关闭或刷新浏览器不停止本机任务；重新连接先恢复服务端快照、已保存消息与产物，再接收增量变化，正确显示离线期间的完成、失败、待决定及同步状态。
- [x] 重连不重复显示消息、不重复提交写作要求、作者确认或定稿；结果未知时先查询真实结果，不能盲目重放请求。
- [x] 上次作品、每部作品的未发送输入及阅读对象可正确恢复，已有任务不重复创建；连接失败与业务执行失败分别呈现。
- [x] 本机服务退出后重新启动，恢复已保存 Context 记录、产物及定稿状态；旧子 Agent 显示中断或终止，不继续播放假进展，不把历史记录当作活跃执行。
- [x] 作者继续修改时，Context 根据保存要求与明确稿件重新安排不可恢复的 Writer 并说明情况；不承诺原子 Agent 精确续跑，也不重做已完成定稿。
- [x] 服务恢复此前执行任务时按同步约定继续未完成同步，并遵守单任务约束；等待作者决定或已被作者明确停止的工作不自动执行，单纯切换查看作品也不触发恢复。
- [x] 在可控模型测试中覆盖生成、修改、等待决定、定稿后同步失败与主动停止等时点的重连或重启；核对记录、产物、正式资料和继续后的实际结果，半份产物不可定稿。
- [x] 运行既有类型检查与业务回归，并在真实页面检查桌面、约 390px 窄屏、键盘焦点、减少动态效果和错误显示；仅对新增恢复行为补充必要测试，不复制前置票验收。
- [x] 使用独立验收作品与现有可用模型配置完成真实“讨论 → 写作 → 自动方案检查 → 初稿与检查 → 阅读并修改 → 新稿 → 指定版本定稿 → Context 同步”，核实四个角色的工作与实际保存结果。
- [x] 在真实验收中再进入第二部作品，验证运行中切换、明确停止、切回、浏览器刷新和服务重启后继续；竞争、异常流与冲突组合由可控模型测试覆盖，不要求制造真实服务商故障。
- [x] 留下可复现的验收记录，分别列明自动化、浏览器与真实模型结果、环境和未覆盖项，不记录凭证。未完成真实模型链路不能标记产品接入完成，质量门禁通过也不宣称文学质量已被作者认可。
