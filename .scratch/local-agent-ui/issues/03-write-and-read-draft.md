# 03 — 写一章并阅读交稿

**What to build:** 作者在任务中提出明确写作要求，看到真实的准备、方案、写作和检查过程，随后从交稿消息打开完整正文和该版本的检查结论。

**Blocked by:** 02 — 进入作品并与 Context 对话。

**Status:** ready-for-agent

**Implementation:** completed · 2026-10-04

对应规格：Noya 本地 Agent 任务界面 MVP；用户故事 15–25，及自动返修、执行状态与失败边界。

- [x] 从页面发出写作要求后，Context 整理作者已接受的 Writing Brief 与相关 Context Pack，保存 Writing Package 并派 Writing Agent；不把整段作者对话和废案传给 Writer。
- [x] Writing Agent 先提交章节方案，Context 检查通过后自动推进正文；仅关键创作分歧返回作者决定，不增加常规“批准方案”按钮。
- [x] 通过真实运行与保存结果呈现执行摘要，详情可区分参与的角色；等待子 Agent 时仍占用当前作者任务，不能因 Context 暂时空闲而允许另一任务执行。
- [x] 正文检查员针对明确稿件及其材料进行检查，每次正文修订使用新检查员；Context 核实待核实项，只将有依据的冲突作为修正要求，区分编辑建议。
- [x] 自动返修按规格的通过、重复冲突未解决或冲突数量不下降条件停止；交稿披露剩余问题，不能把交稿标成全部通过或已定稿。同步修订 ADR 0001 中与已确认停止条件冲突的旧说明。
- [x] 已保存的完整稿件在消息中提供阅读入口，正文、章节标题、作品、版本和检查结论关联正确；跨作品、无效或不完整产物引用被拒绝。
- [x] 桌面可并排阅读与查看任务，窄屏采用可关闭阅读层；只读正文不出现直接编辑控件。键盘焦点、Escape 关闭及减少动态效果可用。
- [x] 模型失败、检查失败、保存失败和正常交稿可区分，已有产物保留；半份正文或尚未完成的检查不得标成成功交付。
- [x] 复用既有待同步门禁，待同步章节不能被绕过去准备下一章；页面不提供绕过入口，同步的完整页面交互由 05 完成。
- [x] 用可控模型回复贯穿真实页面、工具和存储，验证方案到交稿、一次自动返修、停止条件和错误交付；断言保存内容与关联身份，不依赖固定计时或内部调用次数。
