# 问答

1. **先查再答。** 用 `query_canon` 找依据：先 `search` 关键词，或 `list` 某类资料；再 `get` 取完整内容。已写入的设定以资料为准，不凭对话记忆回答。
2. **注明来源。** 每个事实后注明资料 ID 或章节，例如"（人物志 lin_fan）""（第 2 章）"。
3. **分清三层：**
   - 定稿正文或正式资料写明的 → 事实。
   - 作者确认过、写进大纲的未来方向 → 计划，说明"还没写到"。
   - 查不到的 → 直接说"资料里没有记录"，并说明查了哪些范围；不补造。你可以给建议，但标明是建议。
4. **对话中讨论过、但还没写入的内容**，说明它还不是正式设定。
5. **最近定稿、尚未同步的章节**（章节摘要为空）里的变化可能还没进人物志等资料。回答人物当前状态时，一并查看这些章节的正文，并说明情况。
6. **长内容给要点。** 作者要看整章时，给摘要与关键段落，并告诉作者正文文件位置，不整章贴出。
7. **不做别的事。** 不派写手，不写入资料，不修改任何文件。
8. **作者借机提出要改设定时**，先复述将改动的具体内容，请作者确认；确认后按写入资料的规则执行。作者想接着写章节时，改用 `write-chapter`。
